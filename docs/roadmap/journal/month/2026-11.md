## 这个月

- **栈换了**：ADR-0009 确认 Native Runtime，Tauri 壳退为过渡；原生壳四个 crate，egui/eframe 钉 0.31，升级即作废全部归档样本。
- **Phase 0.5 收口**：窗口生命周期改成按需创建、关闭即销毁，静置 600 → 282.8 MB（−53%）；计时契约落地，p50 87 / p95 101 / p99 130 ms 成为原生壳的对照组。
- **G0 有条件通过**：热唤起 p95 48.9 ms、键入 p95 4.95 ms，四个 spike 全部完成。两条未达判据（三种输入法各 30 分钟、130.1 vs 65 MB）没有降级成"以后再说"，而是转成有期限的退出条件。
- **C1 关闭**：字库改成只读映射而不是子集化，常驻 130.1 → 91.5 MB，`mapped − none = 0`。门禁同时改口径——只判「commit < 100」会在字库静默加载失败、面板全是豆腐块时也变好。
- **`notes.db` 只剩一份 DDL**：Tauri 与原生走同一把迁移梯子，`user_version` 仍不写（属产品级决定）；守卫翻转成「Tauri 源码里出现 `CREATE` 即失败」。
- **原生壳成了产品件**：单实例（第二次启动是一条请求，不是第二个托盘图标）、Launcher 预创建藏屏外（p95 2.4–3.2 ms）、`--resident` 零窗口满热键。
- **T-Gate 0/1 关闭**：选区捕获先有 18 项门禁再把翻译迁到原生；两个只有原生壳才会有的缺陷——组合键没松开时投递裸字符、同线程粘贴拿到上一份剪贴板——都是门禁逼出来的。
- **接管态不再只是拒绝**：卡片真开窗、`--todo-card` 真转发、工作台每个按钮都由门禁真点（卡片 17 项、管理器 35 项）。
- **回收站三类都有列表**：笔记是表、收集箱是第二张表、脚本是一个目录；`RowKind` 随 Action 走，彻底删除连 `assets/` 的字节一起。
- **治理层同时收口**：`docs/plans` 按状态分五个目录（位置即状态，归档就是 `git mv`）、ADR 有生命周期与季度复查（`amended` 状态 + 双向指针）、路线文档加上字节预算（90.2 → 22.1 KB）。
- **日志分成三层**：日 / 周 / 月各管一个时间跨度，切分键是时间而不是字节；门禁改判父子引用、日志层取消软上限——同一个 40 KB 放在月志上是「摘要没做」的检查，放在日志上只是「别记太多」。
- **这个月确立的方法**：门禁必须先证明能失败——S4 拿 8 次变异杀规则、每一项功能都要端到端真点、口径作废要写明理由而不是悄悄换一个更好看的数字。
