# 进展日志：三层

> 上层：[路线文档](../../roadmap.md)。依据 ADR-0001：路线图只维护当前目标、活跃轨道、验证债与下一队列，不保留长历史。

日期条目住在这里，按三层放。**层的划分键是时间，不是字数**——`2026-W48` 自带"这是哪一周"，切点由日历决定，任何人不用读内容就能判断一条该住哪儿。

| 层 | 路径 | 一个文件管 | 写什么 |
|---|---|---|---|
| 月 | `month/YYYY-MM.md` | 一个月 | 8–12 条「这个月有什么变化」，每条一句 |
| 周 | `week/YYYY-Www.md` | 一周 | 本周一句定调 + 每天一句 |
| 日 | `log/YYYY-MM-DD.md` | 一天 | 原始记录：数字、踩过的坑、为什么这么做 |

## 三条规则

1. **只往上摘，不往下补写。** 日志写完即冻结（只追加）；周与月是它的派生物，可以随时重写重排。所以日志没有字节上限，周与月有——**月志超了上限，说明你在抄日志，不是在摘要**。
2. **可摘性。** 日志每条的第一句必须能独立成句（变了什么 + 为什么 + 数字）。上层只搬第一句，不重写；做不到这一点，三层就会变成同一条事实写三遍。
3. **周按 ISO 归属**（周四所在的那一个月）。否则跨月那一周的归属年年要吵一次。

## 加一条记录时

- 写进当天的 `log/`，没有就新建；
- 当天的日志必须在所属 `week/` 里被链接到，那一周必须在所属 `month/` 里被链接到，那个月必须在 `roadmap.md` 的索引里被链接到；
- 这三条父子引用由 `scripts/check-doc-budget.mjs` 判——它判索引完整性，不判字节数。

早期月份（2026-04、2026-10）是单层的：条目直接按月归档，没有周与日。它们已经冻结，不再增长，规则是「存在即被引用」，不要求它们凭空长出下层。
