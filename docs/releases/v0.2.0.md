# v0.2.0 发布说明

> 发布日期：2026-10-21
> 关联需求：[PRD-v0.2.0.md](../PRD-v0.2.0.md)
> 关联计划：[2026-10-16-v0.2.0-product-delivery-plan.md](../plans/2026-10-16-v0.2.0-product-delivery-plan.md)

## 重点更新

这一版把 EasyFlowHub 从“快速笔记 + 待办 + 脚本”扩展成围绕 `Capture -> Understand -> Retrieve -> Act` 的个人效率 Hub，并统一为 Windows 毛玻璃工作空间。

### 捕获与理解（P0）

- **Launcher 全局入口**：窄长四列紧凑面板（`440 × 860`），支持搜索、最近 / 收藏筛选、键盘与鼠标执行、参数输入和执行结果反馈。
- **Snow Shot 截屏**：Launcher 注册 `external.snow-shot.capture`，经 Snow Shot 官方 MCP bridge 打开可见截图会话；支持 D 盘等非系统盘安装发现、自定义路径优先、MCP 未开启指引和未安装时打开官方安装页。
- **收集箱（Inbox）**：文本、链接、图片、文件和录音统一落入本地收集箱，带来源 / 上下文 / 时间元数据，支持归档恢复和事务性幂等地“整理为笔记”。Launcher 可一键收集剪贴板内容，优先读取系统剪贴板图片（PNG / JPEG / WebP / GIF，32 MB 上限）。
- **翻译**：复用本机 ScriptMgr Relay 的剪贴板 / 选中文本翻译，支持目标语言与模型设置、取消、错误分类、复制译文和写入收集箱；结果面板可显式替换原选区。模型未配置时提供直达“设置 → 翻译”的入口。
- **录音与转写（P2，可选用）**：Windows 默认输入设备采集 `48 kHz / mono / 16-bit PCM WAV`，支持暂停 / 继续 / 停止，音频回流收集箱；转写经本机 Relay 的 OpenAI 兼容接口完成，发送前必须经隐私确认，失败不丢失音频。Voice 仍需 Windows 打包态麦克风与真实 Provider 验收，故 Phase 5 保持进行中，不阻塞本次核心发布。

### 检索与资源管理（P1）

- **文件搜索**：指定单目录的显式索引刷新，文件名 / 路径 / 扩展名与模糊搜索，最近访问排序，文本与小图预览，以及打开 / 定位 / 复制路径 / 重命名 / 移动 / 复制 / 回收站删除。
- **下载队列**：原生 `.part` 临时文件、HTTP Range 续传、暂停 / 继续 / 取消 / 重试、冲突策略和完成后动作（打开、定位、复制路径、加入收集箱）。
- **统一回收站**：笔记、收集项和脚本共用 Manager 回收站，支持恢复、永久删除与清空；收集箱按保留期清理过期项。

### 工作空间与工程

- **毛玻璃主题**：Manager、Launcher、Quick Note、Settings 等主要页面统一 `manager-*` token，支持明暗主题、系统主题跟随，以及关闭模糊时的不透明 fallback 与高对比度可用性。
- **脚本工作台**：脚本从只读列表升级为可管理工作台（源码编辑、手动执行、退出码与输出、运行记录、新建 / 导入 / 删除到回收站）。
- **Relay / 管理 API 安全收口**：管理 API 仅接受 loopback 地址，浏览器来源白名单，配置快照与扩展清单中的密钥、认证 header 和含凭据的 `base_url` 脱敏。
- **开发者模式诊断日志**：native 有界环形缓冲 + `logs/app.log` 轮转 + sidecar stderr 捕获。
- **架构门禁**：CI 新增 import 环、层级反向依赖、原始 `invoke()` 基线与文件规模债检查；本次发布前拆分了 Quick Note 窗口逻辑（快捷键映射、切换器、工具栏、工具面板、图片条）和回收站面板（笔记 / 收集箱 / 脚本三个分区视图），Quick Note 页面与回收站面板均已回落到 500 行阈值以内。
- **发布链路修复**：Go sidecar 新鲜度改为追踪全部 Go 源码与模块文件，Tauri 将 `scriptmgr.exe` 打入安装包资源根目录，Release 工作流补上 Go toolchain、Windows amd64 sidecar 构建和哈希守卫。

## 升级说明

- 数据结构为 additive 迁移（Inbox / 附件 / transcript / 软删除）。直接覆盖安装或使用 portable 版本均可继续使用原有 `notes.db`。
- 应用内更新从 GitHub Release 的 `latest.json` 读取。
- Snow Shot 需要在其「设置 → 系统」中手动开启 MCP integration，否则 Launcher 会给出设置指引。

## 已知限制

- Voice 与转写属于 P2，未纳入本次核心发布门槛；Windows 打包态麦克风、设备占用和真实 Provider 仍待验收。
- 文件检索只支持单个配置根目录，首次索引由用户显式刷新，不提供全盘实时索引。
- 下载队列重启后不会自动恢复未完成任务。
